## Provenance caveat

The final coupling summary records iteration 3 and the values above. However,
the source analysis also points to an iteration-2 statepoint, while the
available statepoint manifests have an older configuration hash. The raw
statepoint matching the final coupling run could not be established from the
available files. No statepoint or numerical array is included here, and these
figures should not be treated as an independently reproducible benchmark until
the run provenance is reconciled.
